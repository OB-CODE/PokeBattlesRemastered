# Project rules for Claude

## Commit messages

- After making changes, always finish the reply with a suggested commit message for the uncommitted work, in a code block so it can be copied.
- Match the existing history: one short plain-English subject line (no prefixes like `feat:`), followed by a few bullet points only when the change covers more than one thing.
- Do not commit or push unless asked. The commit message is for the user to use.
